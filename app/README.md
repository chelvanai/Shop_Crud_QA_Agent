### Shop Curd Smart AI QA Agent

A simple FastAPI shop system with CRUD operations using SQLite, ORM models, and Pydantic for data validation.

Features:
- Basic CRUD for shop entities.
- AI-powered database question answering. Enter questions, and the app generates safe pandas code (only uses table names, doesn't explore raw data).
- User-friendly UI.

How to run:

1. Install dependencies:
   `pip install -r requirements.txt`


2. Create a `.env` file in the `agent` folder with your OpenAI API key:
   `OPENAI_API=your key`


3. Start the application:
   `python main.py`


4. Open the web UI and use the app.

Enjoy easy shop management and smart database queries!
